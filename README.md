# FluxMint 设计资产台

![FluxMint 设计资产台封面](./public/readme-cover.svg)

FluxMint 设计资产台是一款面向设计资源管理的桌面软件，基于 React、TypeScript、Vite 和 Tauri 构建，并提供手机端辅助界面。它把项目文件夹、资源预览、整理操作和历史记录放到同一个工作台里，适合日常管理大量设计素材、模型文件和项目文档。

## 下载与安装

Windows 安装包已发布到 GitHub Release。

- Release 页面: [FluxMint Design Asset Console v0.1.0](https://github.com/suuk324/asset-console/releases/tag/v0.1.0)
- 安装包文件: `FluxMint-Design-Asset-Console-v0.1.0-x64-setup.exe`

安装步骤:

1. 打开 Release 页面并下载安装包
2. 双击运行 `.exe`
3. 按照安装向导完成安装
4. 首次启动后绑定你的项目文件夹

## 核心亮点

- 项目化管理本地文件，按文件夹和工作区组织资源
- 支持图片、PDF、视频和 3D 资源预览
- 提供最近项目、最近文件、重复文件和操作历史
- 支持导入、重命名、移动、删除、恢复等常用整理动作
- 同时提供桌面端和手机端入口
- 适合设计资产、模型、素材、项目文件的日常整理

## 使用说明

1. 启动软件后，在首页新建或绑定一个项目
2. 进入项目工作区，查看文件夹树和文件列表
3. 使用预览区确认资源内容
4. 通过筛选、排序和重复项快速整理文件
5. 通过操作历史回溯最近的导入、移动和删除动作

## 界面说明

- `概览`：查看最近项目、最近文件、重复资源和操作历史
- `项目工作区`：浏览文件夹树、文件列表和资源预览
- `规则`：管理整理和分类规则
- `设置`：切换语言、调整导入行为和应用偏好
- `手机端`：提供移动设备上的浏览和辅助操作入口

## 适合谁使用

- 需要整理大量项目素材的设计师
- 需要按项目维度管理本地文件的团队
- 需要图片、视频、PDF、3D 预览能力的资源工作流
- 想把文件整理做成可重复、可追踪操作的用户

## 从源码运行

```bash
npm install
npm run dev
```

运行桌面壳层:

```bash
npm run tauri:dev
```

## 从源码打包

```bash
npm run tauri:build
```

## 项目结构

- `src/` - 桌面端和手机端前端代码
- `src-tauri/` - Tauri 壳层与 Rust 后端
- `public/vendor/rhino3dm/` - 3D 预览所需运行资源
- `public/screenshots/` - README 截图占位图
- `remotion-intro/` - 片头/片尾视频工程源码

## 常见问题

### 这是什么类型的软件？

这是一个本地优先的设计资产管理工具，不是云盘替代品。它围绕本地项目文件夹工作。

### 支持哪些预览？

当前包含图片、PDF、视频和 3D 资源预览能力，具体表现会依赖资源类型和平台权限。

### 安装包在哪里？

安装包发布在 GitHub Release 页面，不需要从源码自行打包即可直接使用。

### 可以只看源码吗？

可以。这个仓库同时保留了源码和发布资源，方便你二次开发或直接分享给其他人安装使用。
