# 第六阶段真机联调执行清单

## 1. 目的

本清单用于执行 [07_实施步骤与任务拆解.md](./07_实施步骤与任务拆解.md) 中“阶段 6：联调与验收”的人工验证部分。

当前状态：

- 已于 2026-05-07 完成人工验收通过
- 本文档后续保留为复测清单

本清单不增加任何新功能，只验证：

- 第一版主流程是否真实可用
- 安全边界是否在真实浏览器中仍成立
- 上传、下载、预览、重命名在真机上是否稳定

## 2. 联调前提

执行前必须满足：

- 桌面端软件可正常启动
- 局域网服务已开启
- 已手动选择工作目录
- 桌面端已显示访问地址和连接码
- 手机与电脑连接同一 Wi-Fi
- 工作目录内已准备测试文件

建议准备以下测试素材：

1. `sample.txt`
2. `sample.md`
3. `sample.json`
4. `sample.jpg`
5. `sample.pdf`
6. `big-text.txt`，大小超过 2MB
7. `upload-ok.txt`
8. `conflict.txt`
9. `upload-201mb.bin`，大小超过 200MB
10. 一个子目录，例如 `docs`

## 3. 建议测试浏览器

至少覆盖：

1. iPhone Safari
2. Android Chrome
3. 微信内置浏览器

如果时间不足，最低执行顺序：

1. Android Chrome
2. iPhone Safari
3. 微信内置浏览器

## 4. 执行步骤

### 4.1 桌面端状态

1. 打开桌面端设置页
2. 启动局域网面板服务
3. 记录访问地址
4. 记录当前连接码
5. 确认桌面端显示服务状态正常

预期结果：

- 可看到服务已开启
- 可看到至少一个局域网地址
- 可看到连接码
- 初始设备列表为空或仅显示当前已访问设备

### 4.2 登录

1. 手机浏览器打开桌面端提供的地址
2. 输入错误连接码
3. 观察错误提示
4. 输入正确连接码
5. 进入手机端文件浏览页

预期结果：

- 错误连接码被拒绝
- 错误提示明确
- 正确连接码可进入系统
- 登录成功后桌面端设备列表出现当前设备

### 4.3 文件浏览

1. 进入根目录
2. 点击子目录进入
3. 点击返回上一级
4. 重复进入多个目录
5. 观察路径显示和列表刷新

预期结果：

- 根目录可正常显示
- 子目录可进入
- 返回上一级正常
- 根目录下返回按钮状态正确
- 文件夹和文件显示正确
- 页面不出现绝对路径

### 4.4 搜索

1. 在顶部搜索框输入文件名关键字
2. 验证搜索结果
3. 清空搜索关键词
4. 返回普通目录视图

预期结果：

- 结果仅来自工作目录内部
- 搜索结果显示名称和相对路径信息
- 清空搜索后恢复目录视图

### 4.5 预览

依次测试：

1. 图片文件
2. 文本文件
3. PDF 文件
4. 不支持预览的文件
5. 超过 2MB 的文本文件

预期结果：

- 图片可预览
- 文本可预览
- PDF 可走浏览器原生预览
- 不支持类型显示统一提示
- 超过 2MB 的文本不直接加载，只显示限制提示

### 4.6 上传

1. 在当前目录上传 `upload-ok.txt`
2. 观察上传进度
3. 上传完成后验证目录刷新
4. 再次上传同名文件
5. 上传超过 200MB 的文件

预期结果：

- 上传过程可见进度
- 上传成功后当前目录刷新
- 同名文件冲突被拒绝
- 超过 200MB 被拒绝
- 不发生覆盖

### 4.7 下载

1. 下载一个普通文件
2. 观察下载进度
3. 下载图片或 PDF
4. 在网络较慢时再次尝试下载

预期结果：

- 文件可下载
- 下载进度可见
- 下载失败时有明确提示
- 浏览器不显示绝对路径

### 4.8 重命名

1. 选择一个文件重命名为新名称
2. 选择一个文件夹重命名为新名称
3. 尝试重命名为已存在名称
4. 尝试重命名为非法名称，例如包含 `/`、`\`、`..`

预期结果：

- 文件可重命名
- 文件夹可重命名
- 同名冲突被拒绝
- 非法名称被拒绝
- 成功后页面刷新正确

### 4.9 安全边界

手工尝试访问以下地址：

1. `/api/files?path=../`
2. `/api/files?path=..\\`
3. `/api/download?path=C:\\Windows\\System32\\drivers\\etc\\hosts`
4. `/api/download?path=/etc/passwd`
5. `/assets/../mobile.html`

预期结果：

- 全部被拒绝
- 不返回真实绝对路径
- 不返回底层系统路径细节

### 4.10 弱网与中断

可通过手机系统限速、开发者网络限制或手工断开 Wi-Fi 进行验证。

测试内容：

1. 上传中断
2. 下载中断
3. 登录后网络切换
4. 刷新页面后的恢复情况

预期结果：

- 界面有明确失败提示
- 不出现长时间无反馈状态
- 上传失败不会伪装成成功
- 下载失败不会卡死界面

## 5. 阻断项

出现以下任一问题，应停止进入试用：

1. 任意接口可跳出工作目录
2. 任意返回值包含绝对路径
3. 上传同名文件被覆盖
4. 重命名同名冲突未拦截
5. 连接码逻辑异常
6. 上传或下载没有进度反馈
7. 手机端成功或失败提示不明确
