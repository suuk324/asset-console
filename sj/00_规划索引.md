规划结论摘要：

- 当前项目适合实现该功能
- 推荐基于现有 `Tauri + Rust + React` 架构，在 Rust 侧新增局域网 HTTP 服务
- 手机端应作为独立的移动端 Web 面板，不直接复用桌面端绝对路径数据模型
- 所有文件相关 API 必须统一走 `safeResolvePath`
- 第一版必须强约束范围，只做轻量文件管理，不做外网、不做删除、不做移动、不做批量、不做在线编辑
- 第 6 阶段自动化验收通过后，仍需按真机联调清单完成人工验收
